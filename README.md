# 知量研究学院

独立的新课程网站，目标是能够亲自设计、解释、检验一个预测模型与一份仓位管理章程。与学校 TAC 仓库及旧 quant-from-zero 网站完全分开。

- 网站：https://felixw-123.github.io/quant-research-academy/
- 24 节核心课程、8 个阶段，每节含正文、生活类比、公式、算例、理解检查、任务与答案。
- 原生 SVG 图表：K 线、复利、时间线、样本误差、概率转换、净值与校准图。
- 仓位实验：单笔风险、现金、个股上限、剩余组合计划风险、成本、跳空、连亏、相关性和波动目标。
- 模型实验：逻辑回归、训练内标准化、时间留出、基准、Brier、对数损失、校准、交易账本和测试揭晓记录。
- 毕业设计：模型说明书 + 风险章程，本地自动保存并可导出。

## 学习方法

每次读一课，先手算示例，再做练习。能用自己的语言复述假设并独立完成任务才进入下一课。24 节是完整的核心训练，精通还需要在真实、合规取得的数据上重复研究与失败复盘，不由读完课数或固定天数保证。

毕业证据包括数据卡、程序版本、检验前冻结记录、模型报告、仓位压力报告和至少 20 个交易日的纸面执行日志。20 天检验流程纪律，不证明长期盈利。网站另列收益分布、树模型、组合优化和滚动研究四个进阶方向及一手资源。

## 运行 Python 研究包

Python 3.9+，只使用标准库，不需要 pip，也不需要券商账号。

1. 下载并解压 `research-kit.zip`。
2. 在解压后的目录打开终端。
3. 验证：

```bash
python3 -m unittest test_research.py
```

4. 先看验证段：

```bash
python3 research.py --out experiment-01.json
```

5. 一次改变一个研究问题，并保存尝试记录：

```bash
python3 research.py --features 0,1 --penalty 0.01 --threshold 0.55 --out experiment-02.json
```

6. 冻结特征、惩罚、交易与风险规则后，才揭晓测试：

```bash
python3 research.py --reveal-test --out frozen-test-01.json
```

`--out` 使用创建新文件模式，同名文件已经存在会报错，避免覆盖旧研究。命令行揭晓记录由研究者自己维护；CLI 不会阻止人为反复查看。网页只在当前浏览器记录揭晓状态，更换设备或查看 CSV 仍可能产生人工泄漏。

## 数据与统一协议

`sample_prices.csv` 的 720 行由 `engine.js` 中的固定种子生成，是虚构 OHLC 数据，不对应真实股票。日期只跳过周末，不代表真实交易所节假日历。生成器包含关系和波动变化，是为了演示模型在不同时段表现不一致。

- 输入 X_t：截至 t 收盘的 1 日收盘收益、5 日收盘动量、10 日日收益总体标准差。
- 标签 y_t：若下一日 `close/open - 1 > 0` 则为 1，否则为 0。
- 起始 10 行用来构造特征，末尾没有下一日答案的记录不生成标签。
- 709 条样本按时间分段，训练 425、验证 141、测试 141；两个边界各隔离 1 条。
- 每个训练标签结束时间早于下一段第一个特征时间。多日标签要按实际结束时间增加隔离。
- 均值、标准差与基准概率仅从训练段拟合。当前是单次时间留出；滚动训练属于进阶任务。
- 逻辑回归用 700 次梯度更新、学习率 0.15。目标为平均对数损失 + λ/2 × 非截距系数平方和。本教学实现不声称达到生产级求解器精度。

## 执行与仓位假设

日内做多策略在 t+1 开盘买入、收盘卖出。使用整数股，逐笔更新现金和净值；初始资金 100,000，示例每笔预算 0.5%，资金上限 30%，数量预算价格距离 4%，单边手续费和滑点各 5 bp。所有数值是教学参数，不是个人建议。

**预算距离只用于计算数量，这段日内模拟没有自动止损。** 标签是毛方向，交易层才扣成本。无隔夜持仓、无杠杆、现金收益为 0，无固定最低佣金、停牌、部分成交、容量或市场冲击。回撤基于每日退出后的净值，不包含日内最低点。

仓位函数在四项数量限制中取最小，然后按交易单位向下取整：

1. 单笔预算 / 每股计划损失；
2. 个股资金上限 / 参考买价；
3. 可用现金 / 含费买入成本；
4. 剩余组合计划风险 / 每股计划损失。

买入含费成本为 `P * (1+slip) * (1+fee)`；按止损退出的净收入为 `S * (1-slip) * (1-fee)`。计划损失为两者之差。止损并非成交保证，跳空和极端情景损失可以大于预算；各仓位的计划风险相加也不能描述完整组合尾部。

交易基准每日开盘买、收盘卖，使用相同数量规则与成本。持仓天数不同使平均暴露不同，因此不能只凭最终收益评价模型优势。概率基准始终使用训练段上涨频率。

## 使用真实数据前

`--csv your_prices.csv` 可接收列名为 `date,open,high,low,close` 的文件，日期 YYYY-MM-DD，唯一且递增，至少 80 行。程序检查有限正价格和 OHLC 关系；它无法自动判断数据许可、复权是否一致、历史成分是否完整、数据何时真正发布。

研究者需要补齐数据卡：来源与许可、币种、时区、交易日历、价格调整、公司行动、缺失、退市与历史可得性。不要混合复权收盘和未复权开盘。代码不能作为直接实盘下单系统。

## 隐私与存储

网站不调用行情 API 或券商接口，不上传学习草稿，没有分析追踪代码。进度、实验历史、已揭晓状态与研究草稿存储在浏览器 localStorage；清理浏览器会删除它们。导出的 JSON 用于备份和人工检查，当前界面不提供导入功能。GitHub Pages 的平台访问日志遵循 GitHub 自身政策。
